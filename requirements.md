# System Requirements Documentation

## 1. Hardware Requirements

The following hardware components are proposed for the system:

- ESP32 Development Board
- DHT11 Temperature and Humidity Sensor
- Jumper Wires
- USB Cable

## 2. Software Requirements

- Arduino IDE
- ESP32 Board Support Package
- Embedded C/C++
- DHT Sensor Library

## 3. Functional Requirements

- The system should measure surrounding temperature.
- The system should measure relative humidity.
- The ESP32 should receive data from the DHT11 sensor.
- The ESP32 should process the received sensor data.
- The measured values should be displayed on the Serial Monitor.

## 4. Non-Functional Requirements

- The system should be simple to operate.
- The system should provide readable sensor output.
- The system should operate reliably.
- The system should have low hardware complexity.

## 5. Conclusion

The requirements define the basic hardware, software, and functional needs of the proposed ESP32-based environmental monitoring system.
