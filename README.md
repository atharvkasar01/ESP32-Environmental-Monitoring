# Smart Environmental Monitoring System Using ESP32

## 1. Introduction

The Smart Environmental Monitoring System is an embedded systems project designed to monitor environmental parameters using an ESP32 microcontroller.

The system aims to collect sensor data and provide information about surrounding environmental conditions.

## 2. Objectives

- Understand ESP32 microcontroller architecture.
- Study environmental sensors.
- Analyze sensor interfacing.
- Design a system block diagram.
- Understand embedded system development.

## 3. Proposed Hardware Components

- ESP32 Development Board
- DHT11 Temperature and Humidity Sensor
- Connecting Wires
- USB Cable

## 4. Software Requirements

- Arduino IDE
- Embedded C/C++
- ESP32 Board Support Package
- DHT Sensor Library

## 5. Working Principle

The DHT11 sensor measures the surrounding temperature and humidity and sends the data to the ESP32 microcontroller. The ESP32 processes the received data and displays the measured values on the Serial Monitor.

## 6. Expected Outcome

The proposed system is expected to monitor temperature and humidity using the ESP32 microcontroller and DHT11 sensor.
